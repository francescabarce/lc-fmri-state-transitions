

# Fig. 5 — Human resting-state (awake): LC-map event-wise analysis

This folder contains the code used to reproduce the analyses and figures for **Figure 5** of the paper, focusing on LC-related network dynamics during spontaneous events in **human resting-state (awake) fMRI**.

The pipeline starts from **precomputed similarity traces** between fMRI data and LC-derived spatial maps, and performs:

1. Peak-aligned averaging of LC-map expression  
2. Visualization of LC-map engagement around LC peaks  
3. Event-wise AUC statistics comparing real events to a random-window null model  

No raw fMRI data are required to run this code.

---

## Input data

Place the following files in the `inputs/` folder:

### 1. Similarity traces  
`similarity_trace_combined.csv`

A matrix of LC-map similarity values with:

- Rows: concatenated time points (TRs) from all subjects  
- Columns: LC maps (e.g., `MAP1`, `MAP2`)  

Example format:

```
MAP1    MAP2
-0.12   -0.11
-0.14   -0.12
...
```

### 2. LC peak indices  
`LC_peaks_only.txt`

A text file containing the **global indices** (0-based) of LC peaks in the concatenated similarity trace.

Each index refers to a specific TR across all subjects.

### 3. Analysis parameters (optional but recommended)  
`params.json`

Example:

```json
{
  "tr": 0.58,
  "tr_per_subject": 1050,
  "window_sec_similarity": 30,
  "baseline_win": [-40, -15],
  "t0": -10,
  "t1": 15,
  "n_random": 5000
}
```

If `params.json` is not provided, default values defined in the main script will be used.

---

## What the pipeline does

### 1. Peak-aligned analysis

For each LC peak:

- A ±30 s window is extracted from the similarity trace  
- Windows are z-scored per event  
- Events are grouped across subjects  
- Mean and SEM traces are computed for each LC map  

This produces:

- `outputs/similarity_LC.svg`  
- `outputs/time_axis_LC.npy`  
- `outputs/mean_LC.npy`  
- `outputs/sem_LC.npy`  

### 2. Event-wise AUC metric

For each event:

1. A baseline is computed (e.g. −40 to −15 s)  
2. The trace is baseline-corrected  
3. The full segment is z-scored  
4. The **absolute AUC** of the post-event window is computed:

\[
\text{AUC} = \int |z(t)| \, dt
\]

This quantifies the **magnitude** of LC-map engagement around each event, independent of sign.

### 3. Null model

A null distribution is generated by:

- Randomly sampling time windows of identical length  
- From the concatenated similarity traces  
- Across subjects and time  

This preserves temporal structure but removes event alignment.

### 4. Statistical comparison

For each LC map:

- Real-event AUCs are compared to random-window AUCs  
- Using a two-sided Mann–Whitney U test  
- Significance is shown directly on the plots  

Outputs:

- `outputs/eventwise_auc/Violin_AUC_LC_T1.svg`  
- `outputs/eventwise_auc/Violin_AUC_LC_T2.svg`  
- (One violin plot per LC map)

## How to run

From the `fig5/` folder:

```bash
python main_fig5_from_similarity.py
```

All outputs will be saved in:

```
fig5/outputs/
```

---

## Notes

- Events too close to run boundaries may be partially padded with NaNs and excluded from AUC statistics if baseline windows contain missing values.  
- The AUC metric reflects **magnitude**, not direction.  
- The null model uses random temporal windows.
